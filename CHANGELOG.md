# Changelog

This log records verified changes for this component. Earlier development
history has not been reconstructed.

## 0.1.0

- Initial extracted release of the ESP-IDF Bluetooth HFP client component.
- Provides a public API for HFP connections, call control, device pairing,
  connection status, and Bluetooth statistics.
- Supports sending and receiving SCO audio, with callbacks for application
  audio and status integration.
- Supports using the SBC codec sources bundled with ESP-IDF or the included
  external SBC codec sources.
- The README identifies ESP-IDF 6.0.2 as the validated version. The release
  date is not stated.
